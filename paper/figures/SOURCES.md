# Figure sources and reproduction

- `fly_brain_vnc.png`: original RGBA PNG downloaded September 4, 2026 from
  https://male-cns.janelia.org/_static/mcns_all_neurons_tilt_frontal-1.png
  via https://male-cns.janelia.org/media/ . Credit: Janelia FlyEM and collaborators
  (HHMI Janelia, Cambridge, MRC LMB, Google Research); CC-BY, linked by source
  page to https://creativecommons.org/licenses/by/4.0/ . All-neuron CNS rendering;
  VNC artificially pivoted by source authors for visibility. Brain is anatomical
  context, not a claim that the completed experiment models the entire brain.
  Original pixels preserved; TeX crops transparent margins only. No intensity
  adjustments or generative edits. No anatomical scale asserted.
- `brain_vnc_visualization.pdf` and `.png`: standalone labeled anatomy panel
  built from `fly_brain_vnc.png` and `fly_cns_lateral.png`. Labels identify
  brain and VNC context only; source pixels are unchanged.
- `hexapod_model.png`: native MuJoCo render of `assets/hexapod/hexapod.xml`,
  using the model's `home` keyframe. 1800 x 1350 pixels. Camera, lighting,
  display colors and background changed in memory only. Coincident duplicate
  visual geoms hidden to avoid z-fighting. Geometry, joint state, and source XML
  unchanged. Model preview, not an experimental rollout or gait result.
- `platform_views.png`: three native MuJoCo renders of the same `home` keyframe,
  generated by `render_hexapod.py` at azimuth/elevation pairs (135/-55),
  (45/-33), and (225/-33) degrees. Panels are labeled after rendering; no
  geometry, joint state, or source XML is changed. Model views, not rollout
  frames.
- `manc_connectome_context.png`: existing measured connectivity excerpt,
  retained unchanged from the preceding draft.
- `fixed_motor_map.pdf`, `.png`, and `.csv`: exact affine coefficients from
  `eon-fly-brain/code/mn_to_joint.py::translate`, with gains (-0.55, 0.65, 0.65).
  Input: `eon-fly-brain/results/path2/all_legs_io_index.npz`, SHA-256
  `3f65f5b3ebed0d63161dca416bffa1a55afc0be4906113103426b16492d09449`.
  Unit-vector probes use zero stance. Twenty random inputs with nonzero stance
  verify the affine map against the original function (absolute tolerance 1e-7).
  Each panel retains all channels for one leg, sorted by fly joint then pool
  sign. All panels share a symmetric linear color scale; zero entries are white.
  Cross-leg zeros are omitted from the plot, retained in CSV. Color denotes
  robot-angle coefficient, not synaptic sign. CSV preserves original indices
  and neuron body IDs. No smoothing, fitting, or performance data.
- `brain_vnc_control.pdf` and `.png`: standalone control explanation, deliberately
  not included in the main manuscript. Built with TikZ from unchanged anatomy
  and native MuJoCo source images listed above. Shows the fixed-map pathway;
  the brain is anatomical context, not a simulated whole brain. The separate
  CPG walking interface is explicitly excluded. PNG export is 300 dpi.
- `robustness_rewiring.pdf` and `.png`: rebuilt from the existing E3 and H4
  JSON records using `make_robustness_figure.py`. Data, axes, estimators and
  intervals unchanged; labels enlarged and PDF added for vector reproduction.

Run from repository root:

```sh
eon-fly-brain/.venv/bin/python paper/figures/render_hexapod.py
eon-fly-brain/.venv/bin/python paper/figures/make_robustness_figure.py
eon-fly-brain/.venv/bin/python paper/figures/make_motor_map.py
latexmk -cd -pdf -interaction=nonstopmode -halt-on-error paper/figures/overview_pipeline.tex
latexmk -cd -pdf -interaction=nonstopmode -halt-on-error paper/figures/brain_vnc_visualization.tex
latexmk -cd -pdf -interaction=nonstopmode -halt-on-error paper/figures/brain_vnc_control.tex
pdftoppm -png -r 300 -singlefile paper/figures/brain_vnc_control.pdf paper/figures/brain_vnc_control
latexmk -cd -pdf -interaction=nonstopmode -halt-on-error paper/flycraft_bibm_draft.tex
```
